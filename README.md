# 포트폴리오 웹사이트 (Portfolio)

김승담의 개인 포트폴리오 웹사이트입니다. 영상 제작 및 그래픽 디자인 프로젝트를 소개하는 반응형 정적 웹사이트로, HTML5, CSS3, 바닐라 JavaScript를 사용해 제작했습니다.

## 프로젝트 개요
- **제작자:** 김승담
- **분야:** 영상 디렉터 · 그래픽 디자이너
- **기술 스택:** HTML5, CSS3, Vanilla JavaScript
- **프로젝트 유형:** 반응형 개인 포트폴리오 웹사이트

## 주요 구성 및 기능
1. **고정 상단 내비게이션 & 스크롤 진행률 바:** PC와 모바일 환경 모두에서 편리하게 이동할 수 있는 반응형 헤더와 햄버거 메뉴
2. **풀스크린 히어로 섹션:** 영상·디자인 감성을 담은 전체 화면 배경 이미지와 자기소개 문구
3. **프로젝트 섹션 (3개 카드):** 반응형 그리드로 구성된 주요 프로젝트 카드
4. **Contact 폼:** 이름·이메일·메시지 유효성 검사 및 전송 완료 토스트 알림 기능

## 파일 구조
```text
portfolio/
├── index.html   # 메인 HTML 구조
├── styles.css   # 반응형 레이아웃 및 스타일시트
├── script.js    # 스크롤 진행률, 모바일 메뉴, 폼 유효성 검사
└── README.md    # 프로젝트 설명 문서
```
